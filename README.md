# Torsk — build output

This repository contains **only the compiled game**, served by GitHub Pages.

It is generated. Do not edit anything here by hand — the next deploy overwrites
it. Source lives in a separate private repository; this repo is populated by
running `npm run deploy` there, which copies `app/dist/` into this folder.
